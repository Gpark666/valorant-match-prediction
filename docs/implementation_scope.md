# 경기 데이터 연구와 현재 경기 조회의 구현 범위

경기 데이터 수집·전처리부터 모델 설계·학습, VLR.gg 수집·백엔드와 프런트 수정까지 기술 구현 전반을 본인이 직접 담당했습니다. PM으로는 프로젝트 일정 조율과 핵심 기능 제안을 맡았습니다.

## 오프라인 모델 연구

VCT 2021–2025 CSV에서 경기·팀·라운드 단위로 킬·결과·경제 정보를 결합하고, Game ID와 누적 점수를 이용해 학습 입력을 구성했습니다. 전반 12라운드의 8특성 입력에서 후반 12라운드의 9출력을 예측하는 경로와, 7특성 기반 다음 라운드 승패 예측 경로를 구분합니다.

7특성 1-step 자기회귀 경로에는 accuracy 71.15%의 저장 결과가 있습니다. 이 수치를 다른 Seq2Seq 실험이나 실시간 경기 예측의 정확도로 사용하지 않습니다. 같은 경기의 여러 관점이 분할에 걸치는지와 scaler 적합 시점을 확인하는 것은 재현 시 검토할 항목입니다.

## 현재 경기 수집과 화면 연결

VLR.gg에서 현재 경기 정보를 읽어오는 수집기와 조회 백엔드, 이를 요청하고 표시하는 프런트 수정도 직접 담당했습니다. 목록과 상세 요청은 경기·팀·점수·라운드 정보를 화면으로 전달하는 흐름입니다.

보관된 프런트는 탭 값 또는 경기 식별자가 바뀔 때 fetch합니다. 자동 주기 갱신이나 WebSocket 스트리밍으로 확장해 설명하지 않습니다.

## 모델 연결 경계

프런트 응답 계약에는 `next_round_prob`가 있지만, 실제 수집 데이터를 전처리해 학습 모델에 전달하는 단계는 수행하지 않았습니다. 현재 경기 조회 구현과 실시간 모델 추론의 구현을 구분합니다.

실제 모델 연결에는 사용할 모델 경로의 특성명·열 순서·scaler·시퀀스 길이를 고정하고, 수집 데이터의 누락과 갱신 시점을 처리하는 작업이 필요합니다. 이는 연결을 완성하기 위한 후속 작업입니다.

## 소스 보관 범위

공개용 사본은 학습 노트북과 조회 프런트 소스를 포함합니다. VLR 조회 백엔드는 구현 이력이 있으나 현재 보관본에서는 `.py` 원문 대신 수집기의 바이트코드 흔적과 클라이언트 호출 계약을 확인했습니다. 이 사본에 새 백엔드를 만들어 기존 구현처럼 넣지 않았습니다.
