# Valorant 경기 조회와 라운드 예측

과거 경기 데이터의 수집·전처리와 모델 설계·학습, VLR.gg 수집·백엔드 및 조회 프런트 수정까지 기술 구현 전반을 직접 담당했습니다. PM으로 일정 조율과 핵심 기능 제안도 맡았습니다.

## 담당 범위

| 영역 | 본인 담당 범위 |
|---|---|
| PM | 프로젝트 일정 조율과 핵심 기능 제안 |
| 데이터 | 경기 데이터 수집·전처리와 라운드 시퀀스 구성 |
| 모델 | 예측 모델 설계·학습·평가 |
| 조회 서버 | VLR.gg 현재 경기 수집과 백엔드 |
| 프런트 | 조회 화면의 데이터 연결과 프런트 수정 |

## 두 가지 구현 흐름

VCT 과거 경기 데이터는 라운드·팀 관점으로 재구성해 모델 연구에 사용했습니다. 별도로 VLR.gg에서 현재 경기 상태를 수집하고 백엔드와 프런트를 통해 목록·상세 화면에 연결했습니다.

12×8 입력에서 12×9 출력을 만드는 Seq2Seq와 7특성 기반 다음 라운드 예측은 서로 다른 스키마입니다. 저장 accuracy 71.15%는 7특성 1-step 자기회귀 실험의 결과입니다.

## 구현 범위와 후속 작업

현재 경기 정보를 읽고 화면에 표시하는 조회를 구현했으며 실제 수집값을 예측 모델에 통과시키는 연결은 미수행입니다. 모델별 특성·scaler·시퀀스 길이를 정렬하는 연결 작업은 후속 단계입니다.

현재 공개 사본은 학습 노트북과 조회 프런트를 포함합니다. 조회 백엔드의 `.py` 원문은 현재 보관본에 없으며, 과거 구현과 현 사본의 범위를 구분합니다.
